# Widget App

This is a simple Android widget application demonstrating a countdown widget.

## Features

- **Static Launcher Icon**: The app now uses a static launcher icon (`ic_launcher_static`) to keep a consistent look across devices.
- **Improved Background Image Handling**: `WidgetBackgroundUtils` now requests persistable read permissions for content URIs and safely handles `SecurityException`.
- **Countdown Widget**: Displays a customizable countdown with support for background presets and custom colors.

## Building & Running

Open the project in Android Studio, sync Gradle, and run the app on an emulator or device.
